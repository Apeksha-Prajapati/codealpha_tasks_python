# CodeAlpha Hangman Game

This project is a Python implementation of the classic Hangman word guessing game.

## Description
The player tries to guess the hidden word by entering letters.
The player has limited attempts to guess the correct word.

## Features
- Random word selection
- Limited attempts
- User-friendly console interaction

## How to Run
1. Install Python
2. Open terminal
3. Run:
   python hangman.py

## Concepts Used
- Loops
- Strings
- Lists
- Conditional statements
