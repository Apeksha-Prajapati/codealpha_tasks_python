# CodeAlpha Stock Portfolio Tracker

This is a Python-based stock portfolio tracker created for the CodeAlpha Internship.

## Description
The program allows users to manage stock details like stock name, quantity, and price.
It helps understand basic financial tracking using Python.

## Features
- Add stock details
- Calculate total investment value
- Simple and interactive console program

## How to Run
1. Install Python
2. Open terminal
3. Run:
   python stock_portfolio.py
